Editing a Setup list

Staff pick meal plans, room types, currencies, countries and much more from lists. Add a row, change one, or take one out.

WhoThe administrator
WhereSetup → Setup Menu
Takes1 minute
You needThe new value, spelled as staff should see it

How it works

The Setup Menu holds 29 lists, each on a tile with how many rows it holds. Every list works the same way: New adds a row, clicking a row changes it. A change shows at once in every drop-down that uses the list.

Example in this guide: hotels are starting to offer all-inclusive, so Hotel Meals gets AI, ticked as All Inc.

1. Open the list

1
Click Setup Menu in the menu on the left, then the list, here Hotel Meals. Find a list… at the top searches the tiles.
2
The list shows every row. Click New to add one, or click a row to change it.

2. Add the row

3
Fill the fields. Those marked * are required. Here: type AI in Meal Code and tick All Inc. Click Save. The serial number is given on save.
4
The new row is on the list, and staff can pick it on a hotel line straight away.

3. Taking a row out

Open the row. If anything still uses it, the panel lists what, and the CRM refuses to delete it: a meal plan on last year’s files must stay so those files still read correctly. Some lists switch a row off instead of deleting it, and offer Reactivate to bring it back.

Rename with careChanging a row’s name changes it on every file that uses it, including old ones. To offer something different, add a new row rather than renaming an old one.
